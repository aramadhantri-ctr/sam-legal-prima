# SAM Legal Prima — Multi Page Website

Versi ini dibuat dengan navigasi antar halaman, bukan one-page scroll.

Halaman utama: Beranda, Layanan, Tentang, Proses, Tim, Kontak.
Layanan memiliki halaman detail terpisah.

Tema visual: navy, gold, putih, dan cream mengikuti identitas logo SAM Legal Prima.

Buka folder ini di VS Code lalu jalankan index.html dengan Live Server.
